# LUM-044–053: обзор, полёт и следующий художественный проход

Основание: отзыв пользователя о низкой камере, опускающихся препятствиях, масштабе и отсутствующем прыжке; затем уточнения о движениях в полёте и цели «как мультфильм». База основного проекта ad66a98. Промежуточный кандидат b0d9d34 в отдельном клоне.

## Контракты и границы

- 044: только wall_mesh/world — альфа вместо деформации, живые NodePath окружения с кешированными AABB/RenderState. 044b исправляет различие NodePath/Entity.
- 045: только main/avatar — камера/полёт/состояние. Широкий вариант 14B не принят; main завершён узкими исправлениями 045b/c, avatar заменён отдельным 047.
- 046: только export_pxltiger, затем исправления 046b/c. Базовые FBX/клипы переданы координатором; агент не скачивает файлы. Нормализовать rest-кости и ключи вместе, не scale родителя. Координатор проверяет GLB в настоящем Actor, а не только JSON или exit.
- 047: только avatar — шесть новых клипов, ручное позирование Jump/InAir/Pickup, конечный цикл и точный возврат высоты.
- 048: только wall_mesh — скруглённая геометрия без новых draw calls; 048b корректирует UV. 049: только готовая карта света/её подключение/албедо; приняты модули и узкие API-исправления нескольких моделей после независимого запуска. 050: только кадрирование, без новых правил.
- 051: полный скрипт исправлений от GPT OSS 120B пришёл в stdout; сохранён дословно, просмотрен и запущен координатором на кандидате. 052 сохраняет RGB/RGBA-компоненты при sRGB. 053b — точный JSON-патч длительности полёта, путь/единственность old проверены перед дословным применением.

Процессы OpenCode запускались с индивидуальными тайм-аутами 60–300 с и отдельными клонами. Канонические репозитории на время каждой партии были защищены ACL; каждый runner подтвердил восстановление записи. Приняты только явно названные файлы, конфигурация чужого клона не копировалась. Код реализации — бесплатные маршруты OpenCode; лицензии/ассеты, независимые QA-скрипты/регрессионные тесты, ревью, интеграция и документация — координатор.

## Критерии

Постоянная геометрия препятствий; прозрачность/точное восстановление декора; пропорции в кадре; 5-секундный полёт с взлётом/спуском, разными позами лап/корпуса/хвоста, паузой и возобновлением управления; герой в кадре при обзоре; все четыре темы; большой уровень без регрессии FPS; реальные Game-сцены и Windows exe; источники и лицензия нового персонажа.

Проверенный результат и ограничения — PLAN.md; раздельные качество/доступность моделей и расход — корневой MODEL_JOURNAL.md и CONTEXT_BUDGET.md. Exit 0 и отчёт модели сами по себе не критерии приёмки.
