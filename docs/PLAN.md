# Выполнение проекта

19.10.2026. Семь уровней, оба режима, предметы, Луми, четыре темы, интерфейс и сборка Windows реализованы. Исходный код модулей и регрессионных тестов писали бесплатные модели через OpenCode в отдельных клонах; координатор принимал изменения после просмотра diff и запуска проверок.

## Проверено

- 21 тест `pytest`: генерация, связность, доступность всех предметов до выхода, время, фрукты и очки.
- Программный проход всех семи уровней в Ursina, итог кампании, проигрыш по времени, повтор и полный цикл камеры батута.
- Запуск окна из Python и снимок `--smoke`; сборка PyInstaller и отдельный запуск собранного `.exe` со снимком.
- Проверка синтаксиса `compileall` и чистоты diff.

Снимки и сборка лежат в игнорируемых Git папках `screenshots/` и `dist/`; они создаются локально по README. Датированные наблюдения по исполнителям — в корневом `docs/MODEL_JOURNAL.md`.
