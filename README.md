# Луми и лабиринты

Трёхмерная игра для Windows. Лисёнок Луми ищет выход из семи процедурных лабиринтов: от небольших каменных руин до леса, пещеры и ручьёв. Есть режим на время и Easy без отсчёта. Каждый уровень имеет свой лабиринт, а повтор попытки сохраняет его планировку.

## Запуск готовой игры

Откройте `dist\LumiMaze\LumiMaze.exe`. Для переноса на другой компьютер копируйте **всю папку** `dist\LumiMaze`, включая каталог `_internal`. Интернет во время игры не нужен.

Если сборки нет, запустите игру из исходников в PowerShell из этой папки:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_game.py
```

Проверено на Python 3.13.7, Ursina 8.3.0 и Panda3D 1.10.16 под Windows 11.

## Управление и правила

- **WASD или стрелки** — переход между соседними клетками. Удержание клавиши повторяет шаги; сквозь стены пройти нельзя.
- **Esc или P** — пауза; **R** — повтор текущего уровня; **M** — возврат в меню. На экране результата **Enter** открывает следующий уровень или повторяет проигранный.
- **Яблоко** останавливает таймер на 10 секунд. **Клубника** замедляет отсчёт вдвое; эффект каждой следующей клубники складывается множителем. **Батут** подбрасывает Луми и на несколько секунд показывает лабиринт сверху.
- В **Easy** таймер отключён, а каждое яблоко и каждая клубника добавляют 150 очков. В обоих режимах очки за выход зависят от длины пройденного маршрута: кратчайший даёт 1000 очков, обходы уменьшают награду.

## Разработка и проверка

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
$env:PYTHONPATH = 'src'
.\.venv\Scripts\python.exe -m pytest -q
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

`build.ps1` использует локальное виртуальное окружение и собирает папку `dist\LumiMaze`. Если зависимости уже установлены, повторная сборка не вызывает `pip`. Для снимка окна: `.\.venv\Scripts\python.exe run_game.py --smoke screenshots\preview.png`.
