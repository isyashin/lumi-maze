# Луми и лабиринты

Трёхмерная приключенческая игра для Windows: лисёнок Луми ищет выход из процедурных лабиринтов. Каждый следующий уровень крупнее, тема окружения меняется. Есть режим на время и спокойный Easy без таймера.

**Статус:** разработка. Команды запуска и сборки появятся после интеграции и проверки игры.

Требования и правила игры — [docs/PRODUCT.md](docs/PRODUCT.md). Архитектура и проверка — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
